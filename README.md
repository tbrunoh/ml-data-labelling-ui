# Labeling Service

> A Label Studio deployment for annotating skin tone and skin condition images.

**Part of [Inclusive Skin AI](https://github.com/tbrunoh#inclusive-skin-ai)**, an end to end system for skin analysis built for melanin-rich skin first. Most skin analysis models learn from lighter skin and misread darker tones; this project starts from the other end.

## What it does

Packages [Label Studio](https://labelstud.io) with PostgreSQL and Azure Blob Storage so annotators can label images collected by the [training data API](https://github.com/tbrunoh/ml-data-upload-api). Signup is invite only.

## Quickstart

```bash
git clone https://github.com/tbrunoh/ml-data-labelling-ui.git
cd ml-data-labelling-ui
docker build -t skin-labeling .
docker run -p 8080:80 \
  -e POSTGRE_PASSWORD=... \
  -e STORAGE_AZURE_ACCOUNT_KEY=... \
  skin-labeling
```

Database and storage settings live in the Dockerfile and `config.json`; supply secrets at runtime.
